**Исполнитель:** Александр Болдов

## Описание проекта
Данный проект представляет собой HTML-страницу «О себе», разработанную в рамках выполнения лабораторной работы №1. Веб-страница сверстана с использованием семантических тегов HTML5 и оформлена в тёмно-синей космической гамме с золотистыми акцентами.

## Структура HTML-документа
- **`<header>`** — шапка страницы с именем и тематическим заголовком.
- **`<main>`** — основной блок контента, содержащий:
  - Изображение профиля (`<img>`) с установленными атрибутами `src`, `alt`, `width` и `height`.
  - Секцию **«Навыки»** в виде маркированного списка (`<ul>`).
  - Секцию **«Проекты»** в виде нумерованного списка (`<ol>`).
  - **Форму обратной связи** с полями для ввода имени, email, текста сообщения и кнопкой отправки.
- **`<aside>`** — боковая панель с информацией о любимом созвездии.
- **`<footer>`** — подвал страницы с копирайтом и годом.
